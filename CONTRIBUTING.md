# Как внести вклад

Это советы сообщества (github/opensource.guide), а не юридический источник: перед публикацией сверить с юристом.

## Как запустить проект

1. Калькулятор: открыть `index.html` в браузере — сборка и бэкенд не нужны.
2. Генератор матрицы MVS: открыть `tools/mvs-matrix.html` в браузере.
3. Проверки: выполнить `node --test` в корне репозитория (нужен Node.js 18+).

## Как предложить изменение

1. Создать ветку от `main`.
2. Внести правку одним логическим изменением.
3. Открыть Pull Request с описанием: что меняется и зачем.
4. В описании указать, как проверить правку: команда или сценарий в браузере и ожидаемый результат.

## Стиль

1. Следовать стилю соседнего кода: один HTML-файл, vanilla JS и SVG, без фреймворков и сборки.
2. Не добавлять зависимости: проект должен открываться локально без установки.
3. Не добавлять комментарии в код без необходимости; объяснять решения в документации.

## Лицензия вкладов

1. Вклад принимается на условиях лицензии проекта — PolyForm Noncommercial 1.0.0 (`LICENSE`).
2. Если вклад планируется включить в коммерческую лицензию для организаций, с автором нужно заранее согласовать передачу соответствующих прав. Форма соглашения (CLA) готовится; до её публикации вклады с коммерческим потенциалом лучше обсуждать в Issue до начала работы.

## Как сообщить о проблеме

Через Issues репозитория. В описании укажите принтер, материал, версию браузера и шаги, которые приводят к проблеме.
