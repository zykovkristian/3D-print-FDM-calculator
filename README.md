# 3D-print-FDM-calculator

Что это: интерактивный веб-калькулятор пределов FDM-печати — показывает, что ограничивает скорость и качество, и подбирает настройки для Bambu Studio.
Как запустить: открыть `index.html` в браузере — сборка и бэкенд не нужны.
Где данные: данных нет; параметры и профили катушек хранятся в браузере (localStorage).
Чем собирается: ничем — один HTML-файл с vanilla JS и SVG.
Не трогать: `.kilo/agent-manager.json` — служебное состояние Agent Manager.
