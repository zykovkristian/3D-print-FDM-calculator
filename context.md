# 3D-print-FDM-calculator

Интерактивный калькулятор параметров FDM-печати: по характеристикам принтера
и свойствам конкретной катушки показывает пределы скорости и качества и даёт
настройки для Bambu Studio.

## 1. Цель

Чтобы по характеристикам принтера и свойствам катушки калькулятор выдавал
проверенные пределы и настройки печати, пригодные для Bambu Studio.

## 4. Ограничения

**Do not do**

- **Не добавлять фреймворки и сборку** — проект намеренно один HTML с vanilla JS, открывается локально.
- **Не добавлять бэкенд** — весь расчёт идёт в браузере.
- **Не коммитить секреты** — только имена переменных; значения не попадают в историю.
- **Не трогать `.kilo/agent-manager.json`** — служебное состояние Agent Manager.
