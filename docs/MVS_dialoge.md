2. Лабиринтная траектория
Здесь я предлагаю использовать не обычную спираль Архимеда, а специальную траекторию с двумя взаимосвязанными ветвями.

The Russian Labyrinths (Babylons) on the Solovetsky Islands in the White Sea | blogmymaze
Принцип:

Экструзия начинается на внешнем радиусе.

Траектория закручивается к центру цилиндра.

В центральной зоне выполняется плавный разворот.

Вторая ветвь возвращается наружу по соседнему каналу.

Вся траектория должна оставаться одной непрерывной линией.

Это даст существенно большую длину траектории в пределах одного цилиндра.

Но есть важное инженерное уточнение: обычный Vase Mode в OrcaSlicer не умеет автоматически строить такую траекторию. Потребуется собственный генератор G-code.

Важный момент: цилиндры должны печататься послойно, а не последовательно по всей высоте.

То есть:

сначала все шесть цилиндров достигают высоты первой температурной зоны;

затем принтер стабилизирует новую температуру;

все шесть продолжают печататься на следующем температурном уровне.

Так мы сравниваем шесть VS при одинаковой температурной истории.

5. Технические ограничения, которые нельзя игнорировать
Есть три условия для корректной реализации.

Две спиральные ветви должны быть соединены в одну непрерывную траекторию. Две действительно замкнутые независимые петли уже не будут одной непрерывной линией.

Соседние участки не должны пересекаться или сливаться. Необходим расчёт минимального расстояния между центральными линиями дорожек.

При переходе между цилиндрами необходимы холостые перемещения без экструзии. Это потребует отдельной логики переходов и контроля наплывов.

Также нужно проверить, что лабиринтная геометрия не создаёт внутренние стенки, которые будут мешать оценке внешней оболочки.

Важное уточнение по геометрии
В этой версии реализована однолинейная архимедова спираль с чередованием направления на слоях. Это первый алгоритмический вариант лабиринтной траектории, а не окончательно проверенная геометрия двухзаходной замкнутой спирали.

Внешняя оболочка пока не является гладким цилиндром с внутренним лабиринтом: для такой конструкции потребуется уже несколько независимых стенок, что меняет условия Vase Mode.
