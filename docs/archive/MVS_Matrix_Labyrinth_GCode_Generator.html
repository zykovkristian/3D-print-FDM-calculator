MVS MATRIX · LABYRINTH PATH · A1 MINI

Генератор G-code
для матрицы MVS

Шесть независимых цилиндрических ячеек с длинной спиральной траекторией-лабиринтом. Температура меняется по высотным зонам, VS — отдельно для каждого цилиндра.

Экспериментальный режим. Генератор создаёт только траекторию печати. Это не полный машинный файл Bambu: штатный start/end G-code, очистка сопла, парковка и служебные макросы не встроены. Добавьте проверенные команды из своего профиля Bambu Studio/OrcaSlicer для A1 mini и обязательно проверьте файл в симуляторе. Не отправляйте файл на принтер напрямую без проверки.

1. Геометрия ячеек

Траектория — архимедова спираль от внешнего радиуса к центру. Направление чередуется на каждом следующем слое: внутрь / наружу. Это одна непрерывная экструзионная линия по Z, а не шесть отдельных периметров.

2. Температура и VS

Значения VS задаются для каждого цилиндра. При 6 ячейках значения: 5 / 8 / 11 / 14 / 17 / 20 мм³/с.

Формула: VS = ширина линии × высота слоя × скорость. Экструзия E вычисляется по длине XY-траектории и площади сечения филамента. Генератор использует относительную экструзию (M83), абсолютные XYZ (G90) и стандартные команды G0/G1/M104/M109/M140/M106. Реальные лимиты и поведение прошивки должны быть проверены в слайсере/симуляторе.
