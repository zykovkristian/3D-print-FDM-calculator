## decisions

1. **Публикация отдельной веткой `public`, отправка fast-forward.** Первый снимок ушёл force-push (история была корневой и не родственной), дальше публикация идёт обычным `git push origin public:main` — опубликованная история не переписывается. Локальная `main` с внутренними файлами (`AGENTS.md`, `context.md`, `docs/internal/`, `docs/session-log.md`, `docs/MVS_dialoge.md`) остаётся непубличной.
2. **Лицензия PolyForm Noncommercial 1.0.0** для кода и документации, коммерческая лицензия для организаций — по запросу (юрист ещё не привлекался, `context.md` §7 строка 19).
3. **Горячая температурная зона снизу по умолчанию** (`tempHotBottom`). Раскраска карты T переведена на фактическую температуру зоны, а не на индекс — иначе инверсия зон не отражалась в цвете.
4. **Температура осталась отдельной осью эксперимента**, а не повтором: матрица даёт `VS × T` точек за один прогон (20 точек при 5 ячейках и 4 зонах), отчёт показывает полную матрицу измерений.
5. **AUTO-режим** (`vsMode: plan`): ряд VS от 25–75 % потолка хотэнда, число слоёв в зоне из окна измерения `minPointSec` (по умолчанию 60 с), проверка вместимости в стол и общего времени печати `maxPrintMin` (240 мин). Геометрия берётся настоящая — та же, что при печати.
6. **Плот (raft) переписан по данным ресёрча** (Bambu Studio / OrcaSlicer / Cura / PrusaSlicer): форма = объединение окружностей спиралей с расширением (не прямоугольник по габариту), структура «низ сплошной расширенный → середина разреженная → верх сплошной», зазор контакта с моделью 0.1 мм, свои скорость и температура. Brim и raft взаимоисключающие.
7. **Окно измерения точки оставлено на 60 с** — по решению пользователя; альтернатива 120–180 с (оценка поверхности) не выбрана, строка `context.md` §7 номер 24 открыта.
