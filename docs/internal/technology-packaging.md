# Варианты упаковки MVS Calibrator

## Вариант 1. Source-available набор (рекомендуемый старт)

1. Состав: калькулятор, генератор MVS, протокол и документация в одном репозитории.
2. Доступ: бесплатно для разрешённого некоммерческого использования; коммерческим организациям — отдельная лицензия по запросу.
3. Плюс: пользователи видят метод, могут проверять расчёты и предлагать улучшения; не нужны сервер и сборка.
4. Минус: это не OSI open source, а браузерный код читаем. Доход зависит от ценности лицензии и поддержки, не от сокрытия исходников.

## Вариант 2. Открытый протокол + платная проверка производителя

1. Состав: открытая методика и отчёт, плюс согласованная процедура проверки конкретного материала или принтера.
2. Платит: производитель филамента/принтера за испытательный отчёт, право на согласованную маркировку и обновление профиля.
3. Плюс: доход связан с реальной экспертизой и воспроизводимыми результатами.
4. Минус: прежде чем называть услугу сертификацией, нужны критерии, повторяемость, образцы, правила отзыва и независимое подтверждение.

## Вариант 3. Хостируемый веб-сервис

1. Состав: калькулятор в браузере, сохранение профилей и измерений, экспорт отчётов.
2. Доступ: бесплатная базовая версия; организациям — договорённый коммерческий доступ.
3. Плюс: простой пользовательский путь и возможность обновлять материалы централизованно.
4. Минус: нужна инфраструктура, поддержка и политика приватности. GitHub Pages не скрывает клиентский код и не является полноценным серверным продуктом.

## Вариант 4. Встраиваемый пакет для компаний

1. Состав: отдельный модуль расчёта, API или локальный пакет для производителя слайсера, принтера или филамента.
2. Платит: компания за право интеграции, white-label, обновления и поддержку.
3. Плюс: высокий B2B-потенциал без массового потребительского маркетинга.
4. Минус: потребуются стабильный интерфейс, тестовый набор, документация интеграции, договор и поддержка.

## Вариант 5. Физический калибровочный набор

1. Состав: печатные тестовые образцы/шаблоны, инструкция и доступ к цифровому калькулятору.
2. Платит: энтузиаст за готовый набор или спонсор за разработку.
3. Плюс: хорошо демонстрируется на MakerWorld и в краудфандинговой презентации.
4. Минус: пока не подтверждены печать матрицы MVS и измерения на реальном принтере; производство набора преждевременно.

## Рекомендуемая последовательность

1. Запустить вариант 1 после закрытия техдолга и подтвердить работу тестов.
2. Сначала предлагать компаниям индивидуальную коммерческую лицензию, без публичного прайса.
3. Проверить спрос через запросы производителей; только после воспроизводимых испытаний развивать вариант 2.
4. Не строить SaaS, API или физический продукт до подтверждения спроса и доступного бюджета.
